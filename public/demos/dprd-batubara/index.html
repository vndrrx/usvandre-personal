Sejahtera Berjaya · Periode 2024–2029

Kabupaten Batu Bara terletak di pesisir timur Sumatera Utara (Selat Malaka) dengan ibu kota di Kecamatan Lima Puluh. Resmi berdiri pada 15 Juni 2007 berdasarkan UU No. 5 Tahun 2007, daerah ini dikenal melalui sektor kelautan, pertanian, perkebunan, dan kawasan industri strategis.

Skema Database MySQL: mediaberita (6 Tabel)

Struktur 6 tabel relasional MySQL pada aplikasi lokal XAMPP (C:\xampp\htdocs\DPRD Batubara):

berita
  • PK id int(11)
  • judul_berita varchar(250)
  • isi_berita text
  • tanggal_post date
  • FK penulis_berita int(11)
  • gambar varchar(120)
  • views_count int(11)
  • comment_count int(11)
users
  • PK id int(11)
  • username varchar(20)
  • password varchar(255)
  • gambar varchar(120)
kategori_berita
  • PK id int(11)
  • nama varchar(255)
berita_kategori
  • FK berita_id int(11)
  • FK kategori_id int(11)
comment
  • PK id int(11)
  • FK post_id int(11)
  • name varchar(255)
  • email varchar(255)
  • message text
  • created_at timestamp
views
  • PK id int(11)
  • FK post_id int(11)
  • views_count int(11)
